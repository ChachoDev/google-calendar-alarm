Calendar Alarm

Alarmas locales antes de tus eventos de Google Calendar · open source · MIT

Calendar Alarm es una aplicación de escritorio (Linux, macOS y Windows) que consulta tu calendario y te avisa con una alarma configurable antes de que empiece cada evento.

Código fuente Descargas Privacidad

Cómo funciona

  • Pulsas Conectar con Google y autorizas el acceso de solo lectura al calendario.
  • La aplicación consulta tus próximos eventos periódicamente (cada 5–60 minutos, configurable), directamente desde tu equipo.
  • Cuando un evento está a punto de empezar, suena la alarma y aparece el aviso con los datos del evento.

Descargas

  • Linux x86_64 — descargar (no requiere Python; si no arranca, chmod +x calendar-alarm-linux-x86_64).
  • macOS (Apple Silicon) — descargar (arrastra Calendar Alarm a Aplicaciones; al no estar firmada, ábrela con clic derecho → Abrir la primera vez).
  • Windows x86_64 — próximamente.

Los binarios se publican en la página de releases, junto con su SHA-256. También hay un archivo SHA256SUMS con todos.

Privacidad por diseño

  • No hay servidores propios: la aplicación habla directamente con Google.
  • El token de acceso se guarda solo en tu equipo, con permisos restringidos.
  • No se recopilan analíticas, no hay publicidad y no se comparten datos con terceros.

Requisitos

Una cuenta de Google con Google Calendar. El acceso solicitado es calendar.readonly: leer eventos, sin poder modificarlos.
