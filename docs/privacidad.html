Política de privacidad

Calendar Alarm · Última actualización: 13 de noviembre de 2026

Esta política explica qué información trata Calendar Alarm («la aplicación»), una aplicación de escritorio de código abierto distribuida en github.com/ChachoDev/google-calendar-alarm, y cómo se usa el acceso a tu cuenta de Google.

1. Qué datos se accede

  • Dirección de correo electrónico de la cuenta de Google conectada, únicamente para mostrarte qué cuenta está activa en la aplicación.
  • Eventos del calendario (título, descripción, ubicación, fecha y hora) del calendario principal, con permiso de solo lectura (https://www.googleapis.com/auth/calendar.readonly).

La aplicación no crea, modifica ni borra eventos, y no accede a contactos, correo, archivos ni a ningún otro dato de tu cuenta.

2. Para qué se usan

Exclusivamente para programar alarmas locales y mostrarte el aviso del evento antes de que empiece. No se usan para publicidad ni para elaborar perfiles.

3. Dónde se almacenan

  • El token de autorización de Google se guarda únicamente en tu equipo, en el directorio de configuración del usuario, y en Linux/macOS con permisos 600 (solo tu usuario puede leerlo).
  • Los eventos se mantienen en memoria mientras la aplicación está abierta. No se envían a ningún servidor ni se guardan en una base de datos.
  • La aplicación no tiene servidores propios: las consultas van directamente de tu equipo a la API de Google Calendar.

4. Con quién se comparten

Con nadie. No hay analíticas, publicidad, rastreadores ni cesión de datos a terceros. El proyecto no recopila información sobre sus usuarios.

5. Uso limitado de datos de Google

El uso y la transferencia que Calendar Alarm hace de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado (Limited Use).

6. Conservación y eliminación

  • Puedes desconectar la cuenta desde la propia aplicación («Desconectar» / «Cambiar de cuenta»), lo que borra el token local.
  • Puedes revocar el acceso en cualquier momento desde myaccount.google.com/permissions.
  • Al desinstalar la aplicación puedes eliminar el directorio de configuración (~/.config/CalendarAlarm en Linux) para borrar cualquier resto.

7. Seguridad

La comunicación con Google se realiza mediante HTTPS. El token se almacena localmente con permisos restringidos y nunca se transmite a terceros.

8. Menores

La aplicación no está dirigida a menores de 13 años y no recopila datos de menores de forma consciente.

9. Cambios en esta política

Si esta política cambia, se actualizará esta página y la fecha de la cabecera. Los cambios relevantes se anotarán en el historial del repositorio.

10. Contacto

Para cualquier duda sobre privacidad: victorcanoje@gmail.com.

Privacy Policy

Calendar Alarm · Last updated: November 13, 2026

This policy explains how Calendar Alarm (the “app”), an open-source desktop application distributed at github.com/ChachoDev/google-calendar-alarm, handles your information and your Google account access.

1. Data accessed

  • The email address of the connected Google account, only to show which account is active in the app.
  • Calendar events (title, description, location, start and end time) from your primary calendar, with read-only access (https://www.googleapis.com/auth/calendar.readonly).

The app does not create, edit or delete events, and does not access contacts, email, files or any other account data.

2. Purpose

Solely to schedule local reminder alarms and show event details before an event starts. Data is not used for advertising or profiling.

3. Storage

  • The Google OAuth token is stored only on your device, in the user configuration directory, with 600 permissions on Linux/macOS.
  • Events are kept in memory while the app is running. They are not sent to any server and are not stored in a database.
  • The app has no backend servers: requests go directly from your device to the Google Calendar API.

4. Sharing

None. There are no analytics, ads, trackers or third-party data sharing. The project does not collect information about its users.

5. Google Limited Use

Calendar Alarm’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention and deletion

  • You can disconnect the account from the app, which deletes the local token.
  • You can revoke access at any time at myaccount.google.com/permissions.
  • If you uninstall the app, you may delete its configuration directory (~/.config/CalendarAlarm on Linux) to remove any remaining data.

7. Security

Communication with Google uses HTTPS. The token is stored locally with restricted permissions and is never transmitted to third parties.

8. Children

The app is not directed to children under 13 and does not knowingly collect data from children.

9. Changes

If this policy changes, this page and the date above will be updated. Material changes will be recorded in the repository history.

10. Contact

Privacy questions: victorcanoje@gmail.com.
